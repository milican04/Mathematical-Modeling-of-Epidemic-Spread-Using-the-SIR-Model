# Mathematical Modeling of Epidemic Spread Using the SIR Model

This repository contains numerical simulations developed for a scientific computing (naučno izračunavanje) project. The codebase implements the Susceptible-Infectious-Recovered (SIR) compartmental model using Forward Euler and 4th Order Runge-Kutta (RK4) numerical solvers to analyze infectious disease dynamics and to explain SIR model's properties.

Data Sources
COVID-19 Incidence Data (Serbia, 2021): https://ourworldindata.org
1978 British Boarding School Influenza: https://www.kaggle.com
